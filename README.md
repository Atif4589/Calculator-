# Modern Calculator

A sleek, neon-themed calculator built with plain HTML, CSS, and JavaScript — no frameworks, no dependencies. Just open the file and start calculating.

![Made with HTML](https://img.shields.io/badge/HTML-5-orange) ![Made with CSS](https://img.shields.io/badge/CSS-3-blue) ![Made with JavaScript](https://img.shields.io/badge/JavaScript-Vanilla-yellow)

## Features

- 🎨 Glowing neon gradient UI with a dark theme
- 🔢 Live expression preview above the result as you type
- ➗ Full support for `+ − × ÷ %` and parentheses
- ⌫ Backspace and AC (clear all)
- ⌨️ Keyboard support (numbers, operators, Enter, Backspace, Escape)
- 🧹 History clears automatically after pressing `=`
- 📱 Responsive layout for smaller screens

## Getting Started

No installation or build steps required.

1. Download or clone this repo
2. Open `calculator.html` in any browser
3. Start calculating

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

Then just double-click `calculator.html`, or open it via your browser's File > Open menu.

## Usage

| Key           | Action                          |
|---------------|----------------------------------|
| `0-9`         | Enter digits                    |
| `+ − × ÷`     | Basic operations                |
| `%`           | Percentage                      |
| `( )`         | Smart parentheses insertion     |
| `AC`          | Clear everything                |
| `⌫`           | Delete last character           |
| `=` / Enter   | Evaluate the expression         |

## Tech Stack

- HTML5
- CSS3 (gradients, custom keypad styling)
- Vanilla JavaScript (no libraries)
